# تنظيف المشروع وإعادة كتابة وصف التطبيق على GitHub (Nabih Wallet)

تهدف هذه الخطة إلى إزالة جميع الإشارات أو التعليقات المرتبطة بـ Google AI Studio أو Gemini من ملفات المستودع، وإعادة كتابة ملف تعريف المشروع (`README.md`) ووصف التطبيق باللغة العربية بأسلوب مختصر وبسيط جداً يركز على فكرة التطبيق ومميزاته الأساسية دون أي تعقيدات تقنية.

## قرارات المراجعة المعتمدة

> [!IMPORTANT]
> تم اعتماد التفضيلات التالية بناءً على إجاباتك:

- **لغة الوصف وملف التعريف (`README.md`)**: اللغة العربية فقط.
- **أسلوب ومحتوى الملف**: وصف مختصر وبسيط جداً يوضح فكرة التطبيق ومميزاته للمستخدم دون تفاصيل تقنية أو أوامر برمجية.
- **حذف رابط الوصف في صفحة GitHub الرئيسية (About)**: بالإضافة لتنظيف ملفات الكود، سنوضح خطوة إزالة الرابط المضاف تلقائياً في خانة **Website** داخل إعدادات **About** في صفحة مستودع GitHub.

---

## 1. نظرة عامة والمفهوم الأساسي

- **ما الذي سيتم تنفيذه**:
  1. تنظيف ملفات البيئة والـ Workflows (`.env.example` وملفات GitHub Actions) من أي إشارات أو تعليقات تذكر Google AI Studio أو مفاتيح Gemini غير المستخدمة.
  2. تحديث الوصف العام للتطبيق ليعكس الهوية البصرية الداكنة الجديدة لتطبيق **محفظة نبيه (Nabih Wallet)**.
  3. استبدال محتوى ملف `README.md` الإنجليزي المطوّل بملف عربي أنيق، مختصر، ومباشر يشرح وظيفة التطبيق الأساسية (متابعة الدخل والمصروفات، إدارة الديون، وتصدير التقارير).
  4. تزويدك بنص قصير جاهز للنسخ لوضعه في خانة **Description** في إعدادات **About** على GitHub بعد مسح رابط AI Studio منها.

---

## 2. هيكل الوصف الجديد وتجربة القراءة

- **الهوية النصية لملف `README.md` الجديد**:
  - **العنوان**: `محفظة نبيه | Nabih Wallet`
  - **النبذة المختصرة**: جملة واضحة تعرّف التطبيق كأداة شخصية بسيطة وسريعة لإدارة المصروفات والديون اليومية بواجهة عربية داكنة ومريحة للعين.
  - **المميزات الأساسية (نقاط مختصرة فقط)**:
    - متابعة الدخل والمصروفات وتصنيفها بسهولة.
    - إدارة الديون (مستحق لي / عليّ) وتسجيل الدفعات الجزئية.
    - تقارير مالية واضحة مع إمكانية التصدير بصيغة PDF.
    - نسخ احتياطي واستعادة للبيانات لحفظها بأمان.

---

## 3. القرارات الأساسية

- **تنظيف ملفات الإعدادات والـ Workflows**:
  - *الأسلوب المتبع*: إزالة جميع التعليقات والمتغيرات التي تشير إلى `AI Studio` أو `GEMINI_API_KEY` من ملفات المستودع مع الحفاظ على عمل بناء الـ APK بسلاسة تامة.
  - *السبب*: ضمان خلو المستودع على GitHub من أي نصوص أو إشارات تلقائية لمنصة البناء.
